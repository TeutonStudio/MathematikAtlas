# v2.8.0 Gekoppelte Mengendefinition

## Ziel

Der Knoten-hinzufügen-Dialog erhält den zusammengesetzten Eintrag „Mengendefinition“. Er erzeugt einen Mengenkonstruktor und einen Mengendefinator als semantisch gekoppeltes Paar, jedoch ausdrücklich ohne mathematisch ungültige Direktverbindung.

## Versionswirkung

- reservierte Version: `v2.8.0`
- Versionsachse: `y`
- neue Typ-Schlüssel:
  - `mathematik.mengenkonstruktor`
  - `mathematik.mengendefinator`
- Basis: `v2.7.2` (`f83f841c22cf4903e82596dd300812c2cfc3a3ee`)

## Fachlicher Vertrag

### Mengenkonstruktor

- Parameter: Mengenname, Elementname, Elementtyp und Elementmenge
- Ausgang: `element`
- Standard: `M`, `x`, Zahl, `R`
- erzeugt ein gebundenes Element mit einer nichtpersistierten Herkunftsmarkierung
- zeigt den linken Teil `M={x∈R |` an

### Mengendefinator

- Eingang: `aussage`
- Ausgang: `menge`
- akzeptiert nur eine Aussage, deren Datenfluss das Element des gekoppelten Konstruktors enthält
- bindet ausschließlich dieses Element; andere Parameter bleiben frei
- erzeugt eine symbolische Mengendefinition

## Paarung

Die Paar-ID wird als persistierter Knotenparameter an beiden Endpunkten gespeichert. Sie ist keine Edge und nimmt daher weder an Typprüfung noch Topologie teil. Die zusammengesetzte Erzeugung legt zusätzlich eine visuelle Gruppe an.

Löschen und Duplizieren aus dem Inspektor erweitern die Auswahl auf den jeweiligen Partner. Beim Duplizieren werden Knoten-, Anschluss-, Verbindungs- und Paar-IDs erneuert.

## Verbindungssicherheit

Der Definator besitzt unverändert einen Aussageeingang. Deshalb gilt über die normale Anschlussarthierarchie:

- Zahl → Aussage: abgelehnt
- Aussage → Aussage: erlaubt

Der zusammengesetzte Dialogeintrag erzeugt niemals eine direkte Verbindung. Eine direkte Verbindung ist erst dann manuell möglich, wenn der Elementtyp des Konstruktors auf Aussage gestellt wurde.

## Persistenz

Die Paar-ID liegt in der bereits serialisierten Parameterkarte. Das JSON-Format muss daher nicht angehoben werden. Kartenkopien bleiben unabhängig, weil Paar-IDs nur innerhalb einer Karte ausgewertet werden; die gezielte Paarduplikation vergibt eine neue ID.

## Tests

- Paarerzeugung ohne Edge
- gleiche Paar-ID an beiden Endpunkten
- reelle Standardvariable und Herkunftsmetadaten
- symbolische Auswertung zu `M={x∈R | x<3}`
- Ablehnung eines gleichnamigen Elements aus einem anderen Paar
- direkte Aussageverbindung nur beim Elementtyp Aussage
- direkte Zahlverbindung zum Aussageeingang bleibt abgelehnt

## Abnahme

- Im Dialog existiert genau ein zusammengesetzter Eintrag „Mengendefinition“.
- Der Eintrag erzeugt zwei Knoten und keine Verbindung.
- Eine Prädikatkette zwischen den Endpunkten ergibt eine nutzbare Mengenausgabe.
- Der Definator meldet eine klare Fehlermeldung, wenn die Aussage nicht vom gekoppelten Element abhängt.
- Der Elementtyp aktualisiert Ausgangsart und Verbindbarkeit.
