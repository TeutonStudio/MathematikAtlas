# Architecture Decision Records

Dauerhafte, projektweite Entscheidungen werden als ADR gespeichert.

Namensschema:

```text
NNNN-kurzer-beschreibender-name.md
```

Beispiele:

- `0001-node-registry.md`
- `0002-expression-type-system.md`
- `0003-persistence-versioning.md`

Verwende `../templates/ADR.template.md` als Vorlage.
